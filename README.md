# 卡世界流量卡商城 · 部署包

一套**完整的流量卡商城**，部署到你自己的域名，打开就是一个正常营业的商城。

在售商品为移动、电信、联通三大运营商的大流量手机卡：低月租大流量、全国通用或本省专属，用户线上免费申请，运营商官方审核发货，激活后按套餐资费计费。

## 这个包里有什么

| 模块 | 内容 |
|---|---|
| 商城首页 | 店铺信息、轮播、火爆商品流、公告 |
| 商品列表 | 主图 + 名称 + 标签卡片，按运营商 / 套餐 / 归属地筛选 |
| 智能排序 | 按访客 IP 定位省份，本省专属卡自动置顶 |
| 商品详情 | 主图、详情图文、资费说明、套餐构成、办理协议 |
| 办理申请 | 图形验证码、省市区联动、动态申请表单 |
| 订单查询 | 手机号查询办理进度 |
| 客服与帮助 | 客服入口、常见问题 |

全部开箱即用，不需要申请任何账号、密钥，不需要改任何代码。

## 部署（三步）

```bash
# 1. 下载部署包（Release 里的 liuliangka-mall-dist-v3.zip），解压
unzip liuliangka-mall-dist-v3.zip

# 2. 全部文件上传到你的站点目录，比如 /www/wwwroot/mall

# 3. Nginx 加下面配置，打开你的域名即可
```

```nginx
upstream ksj_mall_api { server ym.ksjhaoka.com:443; }

server {
    listen 443 ssl;
    server_name mall.example.com;          # 换成你的域名
    ssl_certificate     /path/fullchain.pem;
    ssl_certificate_key /path/privkey.pem;

    root /www/wwwroot/mall;
    index index.html;

    # 商城接口反代：前端请求你自己域名的 /api，转发到卡世界后端
    location /api/ {
        proxy_pass https://ksj_mall_api;
        proxy_set_header Host ym.ksjhaoka.com;   # 关键，不带会落到目标默认站点
        proxy_ssl_server_name on;                # 关键，HTTPS 上游必须开 SNI
        proxy_ssl_name ym.ksjhaoka.com;
        proxy_http_version 1.1;
        proxy_read_timeout 60s;
    }

    location / {
        try_files $uri $uri/ /index.html;        # SPA 路由回退，必须有
    }
}
```

打开你的域名，自动进入「号卡办理中心」商城首页并直接出现商品列表，即部署成功。

> 连文件都不想传？还有纯 Nginx 反代的极简方案，一个配置上线整个商城，见 [docs/部署文档.md](docs/)。

## 原理一句话

页面文件跑在你的服务器，商品数据走你自己域名下的 `/api` 反代到卡世界后端，买家提交的办理信息直达卡世界订单系统，不经过你的服务器。

## 可选自定义

- **换店铺**：URL 加 `?s=店铺码` 即可临时切换；改默认店铺就改 `index.html` 里那一行跳转脚本
- **换标题 / 图标**：改 `index.html` 的 `<title>`，替换 `favicon.ico`
- **深度定制**：完整接口文档在 [docs/](docs/)，可自己开发前端对接

## 常见问题

**是正规卡吗？**
都是运营商官方正规卡，套餐资费以运营商官方为准，可在运营商官方 App 查询和管理。

**多久发货？**
提交申请后预计 5 天内由运营商审核发货，可在订单查询页输入手机号和身份证后六位查看进度。

**怎么激活？**
两种方式：快递员上门时现场激活，或收到卡后按随卡说明线上自助激活。

**办卡要钱吗？**
申请本身免费，不收取任何办卡费用。套餐资费在激活后由运营商按套餐规则收取。

**归属地能选吗？**
以商品页标注为准：标注具体省份的为本地归属地卡，标注"随机"的为随机归属地，全国均可使用。

**一个人能办几张？**
按运营商规定，同一身份证在同一运营商名下最多 5 张卡，超出无法通过审核。

**有年龄限制吗？**
一般要求 18-65 岁，具体以商品页标注为准。

**支持选号吗？**
部分商品支持选号，商品页带"可选号"标签的即可在申请时挑选号码。

**不想用了怎么注销？**
通过运营商官方渠道注销：线下营业厅、运营商官方 App 或客服热线均可办理。
